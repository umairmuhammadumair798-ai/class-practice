2. Variables: let and const

A variable is a named box that holds a value. You give the box a name, put something in it, and use the name later.

KeywordCan you reassign it?Use it for
constNoValues that should not change (default choice)
letYesValues that will change (scores, counters)
const courseName = "Web Technologies";   // fixed
let score = 0;                           // will change

score = score + 10;
score = score + 5;

console.log(`Course: ${courseName}, Score: ${score}`);
Course: Web Technologies, Score: 15

The backticks ` with ${ } create a template literal, which lets you put variables inside text. The backtick key is usually just above Tab.

What happens if you change a const?

const pi = 3.14;
pi = 3.14159;       // not allowed
console.log(pi);
TypeError: Assignment to constant variable.

Naming rules

  • Use letters, digits, _ and $. Do not start with a digit.
  • Names are case-sensitive: score and Score are different variables.
  • Use camelCase by convention: studentName, totalMarks.
  • Pick meaningful names: price is better than x.
You may see var in old tutorials It is the older way to declare variables and it has confusing behaviour. In this course, use const by default and let only when the value must change.

5. Working with Strings

const name = "  Ayesha Khan  ";

console.log(name.length);          // 14 (spaces count)
console.log(name.trim());          // "Ayesha Khan"
console.log(name.trim().toUpperCase()); // "AYESHA KHAN"
console.log(name.trim().toLowerCase()); // "ayesha khan"
console.log(name.includes("Khan")); // true
console.log(name.trim().split(" ")); // [ 'Ayesha', 'Khan' ]
console.log("Hello".charAt(0));     // "H"
console.log("Hello".slice(1, 4));   // "ell"
console.log("a-b-c".replace("-", "+")); // "a+b-c"

Methods can be chained: name.trim().toUpperCase() cleans the text first, then changes the case.

6. Making Decisions: if / else

Conditions let your program choose what to do.

const marks = 72;

if (marks >= 80) {
  console.log("Grade A");
} else if (marks >= 60) {
  console.log("Grade B");
} else {
  console.log("Fail");
}
Grade B

JavaScript checks the conditions from top to bottom and runs only the first block that is true.

Shortcut: the ternary operator

const age = 20;
const status = age >= 18 ? "Adult" : "Minor";
console.log(status);   // Adult

switch

const day = 3;
switch (day) {
  case 1: console.log("Monday"); break;
  case 2: console.log("Tuesday"); break;
  case 3: console.log("Wednesday"); break;
  default: console.log("Another day");
}
Truthy and falsy These values count as false in a condition: 0, "", null, undefined, NaN, false. Almost everything else counts as true. That is why if (name) is a quick check for "is the name not empty?".
Try it Write code that stores a temperature and prints "Cold" if it is below 15, "Warm" if it is 15 to 29, and "Hot" if it is 30 or more. Test it with three different numbers.

8. Functions

A function is a reusable block of code with a name. You define it once and call it as many times as you like.

function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Ali"));
console.log(greet("Sara"));
Hello, Ali!
Hello, Sara!
  • Parameters are the inputs in the definition (name).
  • Arguments are the actual values you pass when calling ("Ali").
  • return sends a value back to the caller and ends the function.

Functions with decisions

function getGrade(obtained, total) {
  const percentage = (obtained / total) * 100;
  if (percentage >= 80) return "A (Pass)";
  if (percentage >= 60) return "B (Pass)";
  return "Fail";
}

console.log(getGrade(45, 50));   // A (Pass)
console.log(getGrade(33, 50));   // B (Pass)
console.log(getGrade(20, 50));   // Fail

Arrow functions

A shorter way to write functions, very common in modern code:

const square = (x) => x * x;
const add = (a, b) => a + b;

console.log(square(6));    // 36
console.log(add(2, 3));    // 5
Good function habits Give it one job. Name it with a verb (getGrade, calculateTotal). Prefer return over printing inside the function, so you can reuse the result.
Try it Write isEven(n) that returns true or false. Then write celsiusToFahrenheit(c) using the formula c * 9 / 5 + 32.

9. Arrays

An array is an ordered list of values. Positions (indexes) start at 0.

const fruits = ["apple", "banana", "mango"];

console.log(fruits[0]);        // apple
console.log(fruits.length);    // 3

fruits.push("orange");         // add to the end
fruits.pop();                  // remove from the end
console.log(fruits);           // [ 'apple', 'banana', 'mango' ]
console.log(fruits.includes("banana")); // true
console.log(fruits.indexOf("mango"));   // 2

Even though fruits is a const, you can still add and remove items. const only stops you from replacing the whole array.

Looping through an array

const marks = [72, 85, 49, 91];

for (const m of marks) {
  console.log(m);
}

marks.forEach((m, index) => console.log(`Student ${index + 1}: ${m}`));

Powerful array methods: map, filter, reduce

const marks = [72, 85, 49, 91];

// map: transform every item into a new array
const outOf10 = marks.map(m => m / 10);
console.log(outOf10);          // [ 7.2, 8.5, 4.9, 9.1 ]

// filter: keep only items that pass a test
const passed = marks.filter(m => m >= 50);
console.log(passed);           // [ 72, 85, 91 ]

// reduce: combine everything into one value
const total = marks.reduce((sum, m) => sum + m, 0);
console.log(total);            // 297
console.log(total / marks.length); // 74.25 (average)

10. Objects

An object groups related data under names (called properties). Use one when you are describing a single "thing", such as a student.

const student = {
  name: "Hamza",
  age: 19,
  isEnrolled: true,
  marks: [78, 85, 92]
};

console.log(student.name);        // Hamza
console.log(student["age"]);      // 19

student.age = 20;                 // change a property
student.city = "Lahore";          // add a new property
console.log(student);

Objects with functions

const account = {
  owner: "Sana",
  balance: 1000,
  deposit(amount) {
    this.balance += amount;
  },
  show() {
    console.log(`${this.owner} has ${this.balance}`);
  }
};

account.deposit(500);
account.show();    // Sana has 1500

Arrays of objects (very common in real apps)

const students = [
  { name: "Ali",  marks: 82 },
  { name: "Sara", marks: 67 },
  { name: "Omar", marks: 45 }
];

for (const s of students) {
  console.log(`${s.name}: ${s.marks}`);
}

const names = students.map(s => s.name);
console.log(names);   // [ 'Ali', 'Sara', 'Omar' ]

11. The DOM: JavaScript in the Browser

So far your code printed text. In a browser, JavaScript can also change the web page. The page is represented as a tree of elements called the DOM (Document Object Model), and JavaScript can find and change any element in it.

The three steps of nearly every interactive feature

  1. Select the element: document.getElementById("id")
  2. Listen for an event, such as a click
  3. Change something: text, style, or classes

Live demo

Click the buttons below, then read the code underneath to see how it works.

Welcome to JavaScript!

Count: 0

let currentCount = 0;

function increaseCounter() {
  currentCount++;
  document.getElementById("counter-value").innerText = "Count: " + currentCount;
}

function decreaseCounter() {
  if (currentCount > 0) {
    currentCount--;
    document.getElementById("counter-value").innerText = "Count: " + currentCount;
  }
}

function resetCounter() {
  currentCount = 0;
  document.getElementById("counter-value").innerText = "Count: 0";
}

function changeHeadingColor() {
  const colors = ["#2563eb", "#dc2626", "#059669", "#7c3aed", "#d97706"];
  const randomColor = colors[Math.floor(Math.random() * colors.length)];
  document.getElementById("display-heading").style.color = randomColor;
}

How it works

  • onclick="increaseCounter()" on the button says "when clicked, run this function".
  • getElementById("counter-value") finds the paragraph with that id.
  • .innerText = ... replaces the text shown on the page.
  • .style.color = ... changes the CSS colour directly.
  • Math.random() gives a number from 0 up to (but not including) 1. Multiplying by the array length and using Math.floor picks a random index.

Cheat sheet: common DOM operations

const el = document.getElementById("title");      // select by id

el.style.backgroundColor = "yellow";              // change style
el.classList.add("active");                       // add a CSS class

Task 3: Grade Calculator (Challenge)

Write calculateGrade(obtained, total). Calculate the percentage and return a message such as "82% - A (Pass)".

function calculateGrade(obtained, total) {
  if (total <= 0 || obtained < 0 || obtained > total) {
    return "Invalid input";

  if (percentage >= 60) return `${percentage}% - B (Pass)`;
  return `${percentage}% - Fail`;
}

Task 6: Grade Calculator Page

Two number inputs (Marks Obtained, Total Marks) and a Calculate Grade button that shows the percentage and the grade.

HintInput values are strings. Convert them with Number() before calculating.
Solution 
<input type="number" id="obtained" placeholder="Marks obtained">
<input type="number" id="total" placeholder="Total marks">
<button onclick="calculate()">Calculate Grade</button>
<p id="output"></p>

<script>
  function calculate() {
    const obtained = Number(document.getElementById("obtained").value);
    const total = Number(document.getElementById("total").value);
    const out = document.getElementById("output");

    if (total <= 0 || obtained < 0 || obtained > total) {
      out.innerText = "Invalid input";
      return;
    }

    const pct = Math.round((obtained / total) * 100);
    let grade = "Fail";
    if (pct >= 80) grade = "A (Pass)";
    else if (pct >= 60) grade = "B (Pass)";

    out.innerText = `${pct}% - ${grade}`;
  }
</script>

13. Common Mistakes and Debugging

Every programmer sees errors daily. Reading them calmly is a skill. The message tells you the type of problem and usually the line number.

Error messageUsual causeFix
SyntaxError: Unexpected tokenMissing bracket, brace or quoteCheck the line shown and the line before it
ReferenceError: x is not definedTypo in a name, or the variable was never declaredCheck spelling and capitals
TypeError: Assignment to constant variableReassigning a constUse let if it must change
TypeError: x is not a functionCalling something that isn't a functionCheck the name and that you didn't overwrite it
TypeError: Cannot read properties of undefinedUsing .something on a value that doesn't existLog the value before that line
NaN in the outputMaths on text that isn't a numberUse Number() and check the input

Debugging checklist

  1. Read the error message fully, including the line number.
  2. Add console.log() to see what values your variables really hold.
  3. Test one small piece at a time rather than the whole program.
  4. Check spelling and capitalisation (getElementById is not getElementByID).
  5. Compare with a working example from this guide.

Spot the bug

Each snippet has one bug. Find it before opening the answer.

// Bug 1
const total = 10;
total = total + 5;
console.log(total);
Answertotal is a const and cannot be reassigned. Declare it with let.
// Bug 2
function add(a, b) {
  a + b;
}
console.log(add(2, 3));   // prints undefined
AnswerThe function never returns the result. Write return a + b;.
// Bug 3
const items = ["pen", "book", "bag"];
for (let i = 0; i <= items.length; i++) {
  console.log(items[i].toUpperCase());
}
AnswerThe loop uses <=, so on the last round i is 3 and items[3] is undefined, which crashes. Use i < items.length.
// Bug 4
const a = "10";
const b = "5";
console.log(a + b);   // expected 15
AnswerBoth values are strings, so + joins them into "105". Use Number(a) + Number(b).

14. Self-Check Quiz

Answer in your head or on paper first, then open the answer.

1. What is the difference between let and const?
Answerlet allows the variable to be reassigned; const does not.
2. What does this print: console.log("3" + 4)?
Answer34. With a string on one side, + joins text instead of adding.
3. What is the result of 5 === "5"?
Answerfalse. The values look alike but the types differ (number vs string).
4. What is 17 % 5?
Answer2, the remainder after dividing 17 by 5.
5. For const arr = [10, 20, 30], what is arr[1] and what is arr.length?
Answer20 and 3. Indexes start at 0.
6. What will this print? 
for (let i = 0; i < 3; i++) {
  console.log(i);
}
Answer0, 1, 2 on separate lines. The loop stops before i reaches 3.
7. What does [1, 2, 3, 4].filter(n => n % 2 === 0) return?
Answer[2, 4], only the even numbers.
8. Why do we convert form input with Number()?
AnswerValues read from inputs are always strings. Without converting, + joins them instead of adding.
9. Which error do you get from using document in onecompiler.com/javascript, and why?
AnswerReferenceError: document is not defined. That sandbox runs JavaScript without a web page, so there is no DOM.
10. What are the three steps of a typical DOM interaction?
AnswerSelect an element, listen for an event (such as a click), then change the element (text, style or class).
